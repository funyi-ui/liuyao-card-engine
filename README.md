# 육효카드 엔진 (liuyao-card-engine)

동전 대신 **효 카드 6장**을 뽑아 육효(六爻) 점괘를 만드는 파이썬 엔진입니다.
외부 라이브러리 없이 동작하며, 결과를 JSON으로 내보내 홈페이지 등 다른 서비스에 연동할 수 있습니다.

## 무엇을 계산하나

- 카드 뽑기: 1효→6효, 한 효마다 카드 한 장 (노음 6 · 소양 7 · 소음 8 · 노양 9)
- 본괘 / 변괘 (동효 반영)
- 팔궁 64괘: 소속 궁, 본궁·1~5세·유혼·귀혼, 세효·응효
- 납갑: 효마다 천간·지지·오행
- 육친: 형제·자손·부모·처재·관귀 (변효도 본궁 오행 기준)
- 육신: 청룡·주작·구진·등사·백호·현무 (일간 기준)
- 일진, 월건, 순공(공망)
- 복신: 본괘에 없는 육친을 본궁 순괘에서 찾아 표시
- 육충괘 / 육합괘 표시

해석(용신 선택, 길흉 판단)은 포함하지 않았습니다. 엔진은 괘 구조까지만 계산합니다.

## 설치와 사용

```bash
python -m liuyao_card                                   # 지금 시각으로 카드 6장 뽑기
python -m liuyao_card --seed 7 --date 2026-10-30        # 같은 결과를 재현
python -m liuyao_card --values 8,7,7,9,7,6 --date 2026-10-30   # 1효→6효 값을 직접 입력
python -m liuyao_card --seed 7 --json                   # JSON 출력
```

```python
from datetime import datetime
from liuyao_card import cast, from_values

reading = cast(when=datetime(2026, 10, 30, 11, 27))
print(reading.to_text())
data = reading.to_dict()          # JSON으로 직렬화 가능

reading = from_values([8, 7, 7, 9, 7, 6], when=datetime(2026, 10, 30))
```

### 덱 확률

| method | 노음 6 | 소양 7 | 소음 8 | 노양 9 |
|---|---|---|---|---|
| `coin` (기본) | 1/8 | 3/8 | 3/8 | 1/8 |
| `yarrow` | 1/16 | 5/16 | 7/16 | 3/16 |

## 알아둘 점

- **월건**은 절기 날짜를 공식으로 근사합니다(2001~2100년, ±1일). 절기 경계 근처 날짜는 결과에 안내가 붙습니다. 정확한 값이 필요하면 `month_branch="戌"`처럼 직접 넘기세요.
- 일진 기준은 자정입니다. 23시 이후를 다음 날로 보려면 `day_change_at_23=True`를 쓰세요.
- 복신이 한 육친에 여러 후보로 나올 수 있으며, 어느 것을 쓸지는 해석자가 정합니다.
